# Перенос из direktor

Источник: `mikhaildrobinin-bot/direktor`, ветка `main`. Оригинальный репозиторий не изменялся.

## Импортировано в direktor-gpt

- 13 исходных prompt-файлов из `Контора/prompts/`.
- Правило директора и 13 файлов правил ролей из `Контора/правила/`.
- 12 подробных справочников ролей из `Контора/правила/справочники/`.
- Отдельная роль фарма-стратега из `Контора/роли/farma-strateg.md`.
- `CLAUDE.md` сохранён как справочный исходник.

Файлы источника сохранены без переписывания в `agents/source/`. Активные prompt-файлы `agents/prompts/` заменены оригинальными промптами, чтобы runtime загружал исходные инструкции.

## Адаптация для OpenAI

- Claude-specific механика сессий, локальные пути и команды не исполняются автоматически.
- Роли вызываются через OpenAI Agents SDK как инструменты РП.
- Исходные инструкции и справочники добавляются в контекст соответствующих ролей.
- Внешние действия, shell и production deployment не предоставлены агентам.

## Навыки

Отдельные `SKILL.md` в исходном дереве не найдены. Каталог `skills/registry.yaml` содержит предварительные модули, а не доказанные оригинальные навыки. Их инструкции нужно разработать и протестировать отдельно.

## Что не переносилось как рабочая память

HANDOFF, журнал, портфель, поручения, отчёты, бюджет, лиды и клиентские материалы не подключались к агентам автоматически: там есть устаревающие операционные данные и сведения конкретных проектов. Их нужно импортировать выборочно после ревизии и классификации доступа.
