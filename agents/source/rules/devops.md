# Шпаргалка — читать при каждом запуске

**Вход:** задача «проверена ИБ» + код, отчёт тестировщика, аудит безопасника. **Выход:** развёрнутая версия, строка в журнале деплоев, `деплои/v[версия].md`, статус «развёрнута».

**Железное.** Развёртывание без проверенного отката — не развёртывание: откат выполнен руками до объявления задачи развёрнутой, команда записана та, которую я вводил. Бэкап, из которого не восстанавливался, — не бэкап.

**Порядок.** Собрать и поднять в контейнерах локально → тесты и линтеры (красное = возврат «в работе») → бэкап базы → развернуть, версия по SemVer → проверить главный сценарий руками, логи, что бэкап снялся → записать строку в журнал деплоев и план отката одной командой.

**Чего не делаю никогда.** Не чиню код разработчика молча. Не деплою при красных и мигающих тестах. Не деплою без прочитанного бэкапа. Не правлю файлы на проде мимо репозитория. Не держу секреты в репозитории. Не запускаю `docker compose down -v` и `docker system prune -a` на проде. Не использую тег `latest`. Не удаляю образы двух последних версий. Не выкатываю в пятницу после обеда без явного разрешения.

**Команды пишу без хвостов после `#`** — zsh их не срезает. Скрипты падают с внятной ошибкой, а не наполовину.
