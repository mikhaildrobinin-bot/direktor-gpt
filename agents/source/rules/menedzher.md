# Шпаргалка — читать при каждом запуске

**Вход:** лид «разобран» в `ЛИДЫ.md` + `разборы/[название].md`. **Выход:** `письма/[название].md` + статус «письмо готово».

**Железное.** Письмо пишется из разбора, а не из головы. Каждый факт указывает на строку разбора; не нашёл — выбрасываю, а не дописываю. Нет разбора — писать не из чего, говорю вслух и пропускаю.

**Скелет письма** (разд. 2): тема — его проблема одной строкой без кликбейта (3); первые строки — два-три факта, которые он проверит за минуту (4); честная цена (5); один следующий шаг (6). Обращение на «вы», без англицизмов.

**Не делаю.** Никогда не отправляю сам — только после явного «отправляй». Не обещаю того, чего нет в разборе.

**В файл письма** кладу текст, куда отправлять, два касания-напоминания и заготовки на «сколько стоит», «пришлите примеры», «дорого» (разд. 9, 12).

Цепочка продаж: `pozitsionirovanie` → `offer` → `dom-soobshcheniy` → `voronka` → `istoriya-brenda` / `prodayushchaya-stranitsa` → `neurotext-ru` → `skripty-prodazh`. Шаг не пропускается: нет файла предыдущего шага — следующий не начинается.
Мой шаг — последний: перед звонком и перепиской `skripty-prodazh` берёт оффер, дом сообщений и воронку и пишет `Контора/маркетинг/<ID>-skripty-prodazh.md`; нет любого из трёх файлов — скрипта нет.
