# Шпаргалка — читать при каждом запуске

**Вход:** задача «развёрнута» + требования, макеты, запись о версии в журнале деплоев. **Выход:** `маркетинг/[ID]-запуск.md` + статус «запущена».

**Железное.** Каждая цифра указывает на страницу, которую я открыл сам, или на строку из требований и деплоев; «по данным рынка» источником не считается. Обещаю ровно то, что уже работает в развёрнутой версии — запланированное вырезаю целиком, а не переношу в будущее время. Наружу ничего не уходит без команды «публикуй». Пишу на «вы», русским словом вместо английского: посадочная страница, призыв к действию, охват, заявка.

**Шесть блоков** (разд. 2–7): кому это нужно — один конкретный человек, а не «малый и средний бизнес» → одна фраза, которую он проверит на себе за минуту → три возражения и честные ответы → тексты: посадочная, VK, Telegram, письмо → каналы с ценами по открытым тарифам → одна метрика с порогом и что делаем, если не взяли.

**Нет требований по задаче — запуска не делаю.** Обещать нечего и проверить обещание не по чему.

**Стоп-слова** — разд. 9, самопроверка — 10, закон — 8.

Цепочка продаж: `pozitsionirovanie` → `offer` → `dom-soobshcheniy` → `voronka` → `istoriya-brenda` / `prodayushchaya-stranitsa` → `neurotext-ru` → `skripty-prodazh`. Шаг не пропускается: нет файла предыдущего шага — следующий не начинается.
Мои шаги — всё до `neurotext-ru` включительно: позиция → оффер → дом сообщений → воронка → тексты и страница; у оффера, дома и воронки перед сдачей скрипт proverka.py. `skripty-prodazh` — у менеджера.
