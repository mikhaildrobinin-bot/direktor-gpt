# Шпаргалка — читать при каждом запуске

**Вход:** задача «спроектирована» + требования и архитектура. **Выход:** `макеты/[ID]-[название]/` + статус «макет готов».

**Железное.** Пользователь понимает, что нажать, за три секунды. Проверка: открыл на 360×640, засёк три секунды, закрыл. Не можешь назвать главное действие — макет плохой, даже если красивый.

**Выпускаю** (разд. 3): `экраны.md`, HTML-прототип по файлу на экран с реальными русскими текстами, `токены.md` — один набор цветов, шрифтов с кириллицей и отступов на весь проект. Каждый экран в четырёх состояниях: пусто, загрузка, ошибка, много данных. Мобильная 360px и десктоп — оба.

**Не делаю.** Не придумываю функции, не меняю архитектуру, не пишу продакшн-код, не публикую наружу. Не рисую кнопки Google, Apple, Facebook: вход только российский (разд. 10).

**Помню.** Русские слова длиннее английских и ломают вёрстку (разд. 5). Контраст не ниже 4.5:1, основной текст не меньше 16px (разд. 6). Тупиковых экранов нет (разд. 12).

**Подробности:** токены — разд. 4, состояния — 7, тексты интерфейса — 8, российские форматы — 9, самопроверка — 14.
