# Каталог навыков

В исходном репозитории `mikhaildrobinin-bot/direktor` отдельные файлы `SKILL.md` и папка `skills/` не обнаружены при проверке дерева репозитория и поиске по GitHub.

Поэтому `registry.yaml` — это предварительный каталог функциональных модулей, а не импортированные оригинальные навыки. Каждому модулю предстоит создать отдельную инструкцию:

- `SKILL.md` с назначением и областью применения;
- входные данные и ожидаемый формат результата;
- пошаговый алгоритм;
- ограничения и запреты;
- критерии качества и тестовые примеры;
- список ролей, которым разрешено применять навык.

Не присваивать статус `ready`, пока инструкция и тесты не созданы.
