# direktor-openai

Мультиагентная система на OpenAI Agents SDK. Исходный репозиторий `mikhaildrobinin-bot/direktor` не затрагивается.

Стартовый каркас: иерархия директор → руководитель проекта → 13 специализированных агентов, FastAPI, SQLAlchemy, Docker Compose и CI. Перед запуском задайте `OPENAI_API_KEY` через переменные окружения.

Подробная структура и инструкции будут добавлены отдельными файлами.
